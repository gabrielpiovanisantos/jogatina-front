🐛 ENCONTROU ERRO?
═══════════════════════════════════════════════════════════════════

Erro: "Falha ao conectar com o servidor"
  → Verifique se backend roda em http://localhost:8080
  → Abra DevTools (F12) → Console → procure erro
  → Doc: CHECKLIST.md

Erro: CORS Error
  → Backend precisa de CorsConfig.kt
  → Doc: CHECKLIST.md → Troubleshooting → CORS Error

Erro: npm install falha
  → Execute: npm cache clean --force
  → Depois: npm install
  → Doc: CHECKLIST.md → npm install falha
